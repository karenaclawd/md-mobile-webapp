# Markdown Mobile Reader

Welcome to your pocket markdown studio. This app is designed for fast reading and beautiful presentation on small screens.

## Highlights

- Mobile-first layout with a focus mode
- Smooth, readable typography
- GitHub Flavored Markdown support
- Drag-and-drop or tap to import `.md` files

## Quick Actions

1. Tap **Import** to add your own markdown file.
2. Browse the Library panel to switch documents.
3. Use the **Focus** toggle for distraction-free reading.

> Tip: Try pasting tables or task lists to see the renderer shine.
